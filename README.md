# Sports-Ontology

This repository represents the university course project for "Knowledge Representation and Modeling" course.

## Introduction

This ontology models the domain of sports using Description Logic and is implemented in Python with the owlready2 library. It defines a rich hierarchy of concepts, properties and individuals to enable reasoning and querying over sports-related knowledge.

## Key Features
- Classification of sports by venue (indoor/outdoor), equipment (ball, racquet, net, etc.), physical activity level (low/medium/high), contact type, and team structure (individual/team)
- Modeling of athletes, teams, and their relationships (teammates, team membership, sport participation)
- Logical inference examples
- Consistency checking via owlready2
- SPARQL queries over the knowledge base
- Ontology schema visualization with WebVOWL
